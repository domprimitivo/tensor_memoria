# Cantera Software Use & Legal Disclaimer

## 1. Overview & Purpose
This repository incorporates simulation workflows, benchmarks, and data evaluation scripts that utilize **Cantera**, an open-source suite of object-oriented software tools designed for chemical kinetics, thermodynamics, and transport processes.

Within this project, Cantera is utilized strictly as an external computational engine to generate, evaluate, and validate non-linear chemical kinetic trajectories—specifically focusing on the Negative Temperature Coefficient (NTC) regime and cold-flame dynamics using established reaction mechanisms (such as GRI-Mech 3.0).
